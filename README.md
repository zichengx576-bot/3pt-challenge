# 3PT Challenge

一个基于 Three.js 的 3D 定点三分球挑战游戏。

选择你的投篮点位，在 25 次出手中尽可能获得更高分数。每组投篮包含一枚 2 分花球，精准掌握蓄力时机，挑战每个点位的最佳成绩。

## 功能特色

- 3D 篮球场、篮筐、球员与观众场景
- 支持 5 个投篮点位：
  - 左底角
  - 左侧 45°
  - 弧顶
  - 右侧 45°
  - 右底角
- 每局共 25 次投篮，满分 30 分
- 每第五球为 2 分花球
- 蓄力时机条与绿色精准区间
- 投篮命中、篮筐碰撞和观众音效
- 记录每个点位的最佳分数、命中率、绿点次数和最高连中
- 支持桌面端键盘操作与移动端触控操作
- 支持响应式布局，适配桌面与手机屏幕
- 支持关闭游戏声音

## 快速开始

### Windows 发布版

无需安装 Node.js 或其他开发工具。

1. 下载仓库中的 [`3PT投篮游戏_Windows版.zip`](./3PT投篮游戏_Windows版.zip)。
2. 解压压缩包。
3. 进入发布版目录，双击 `启动游戏.cmd`。
4. 浏览器会自动打开游戏页面。
5. 游戏过程中请保持弹出的黑色服务器窗口开启。

结束游戏时，可以直接关闭服务器窗口。开发版也提供了根目录下的 `关闭游戏.cmd` 停止脚本。

### 从源码运行

环境要求：

- Node.js
- pnpm
- 支持 WebGL 的现代浏览器

安装依赖：

```bash
pnpm install
```

启动开发服务器：

```bash
pnpm dev
```

默认访问地址：

```text
http://127.0.0.1:4173/
```

构建生产版本：

```bash
pnpm build
```

预览生产构建：

```bash
pnpm preview
```

## 操作说明

### 桌面端

1. 选择一个投篮点位。
2. 按住 `Space` 键进行蓄力。
3. 在蓄力条接近绿色区域时松开 `Space` 投篮。
4. 蓄力超过上限后会自动出手。

### 移动端

1. 选择一个投篮点位。
2. 按住屏幕底部的“按住投篮”按钮。
3. 在合适的蓄力时机松开按钮。

## 计分规则

- 普通球命中：`1` 分
- 每第五球为花球，命中：`2` 分
- 每局共 `25` 球
- 最高得分：`30` 分
- 绿色精准区间约为蓄力条的 `75% - 81%`
- 绿色精准出手会判定为完美释放
- 偏早或偏晚的出手仍可能命中，具体结果以游戏实际表现为准

## 成绩记录

游戏会使用浏览器的 `localStorage` 保存成绩，并分别记录每个投篮点位的：

- 最佳分数
- 最佳命中率
- 最多绿点次数
- 最高连续命中数

清除浏览器站点数据后，本地成绩也会被清除。

## 项目结构

```text
src/
├─ main.ts                 # 游戏界面与主流程
├─ style.css               # 响应式界面样式
├─ types.ts                # 类型定义
└─ game/
   ├─ scene.ts             # 3D 场景与动画
   ├─ shot.ts              # 蓄力时机与命中判定
   ├─ scoring.ts           # 计分和回合统计
   ├─ storage.ts           # 本地最佳成绩
   ├─ audio.ts             # 游戏音效
   └─ config.ts            # 点位和游戏参数

tests/
└─ e2e/
   └─ game.spec.ts         # Playwright 端到端测试

发布版/
├─ dist/                   # 构建后的游戏文件
├─ 启动游戏.cmd
├─ start-game.ps1
└─ 使用说明.txt
```
